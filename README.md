# ML_e2e

Ottawa Machine Learning Opearations End to End project

# :star: Project Overview

This project is an end-to-end machine learning application built using TensorFlow (:heavy_exclamation_mark: TODO [include other tech stack used]) to classify clothing images into their correct categories. The final system includes a simple web application where users can upload an image of clothing, and the model will predict the clothing type along with confidence scores.

# :mag_right: Dataset Selection

For this project, I selected the [Clothing Dataset](https://www.kaggle.com/datasets/agrigorev/clothing-dataset-full) published on Kaggle by [Alexey Grigorev](https://www.linkedin.com/in/agrigorev/).
